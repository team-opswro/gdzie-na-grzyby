# E. Dane dla całego kraju na R2 — plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pipeline z bazą DuckDB i domieszkami z paczek BDL buduje wersjonowane dane dla 73 nadleśnictw, publikuje je (i prognozę) na R2/S3, a strona czyta wszystko z bucketu.

**Architecture:** `pipeline.ingest` → DuckDB + GeoParquet; `pipeline.build` → `pipeline/data/out/` (PMTiles, centroidy w kafelkach, grid, nazwy, gatunki); `pipeline.publish` → `v/<build>/` + `manifest.json`; `forecast` czyta grid z bucketu i wysyła `live/pogoda.json`; frontend: `config.json` → manifest → pliki.

**Tech Stack:** Python 3 (duckdb, geopandas, pyarrow, boto3, pytest), tippecanoe, MapLibre GL JS + PMTiles, MinIO (lokalnie), Cloudflare R2.

**Spec:** `docs/superpowers/specs/2026-10-03-e-dane-r2-design.md`

## Global Constraints

- Paczki: `Nadlesnictwa/BDL_<RR>_<NN>_<NAZWA>_<ROK>[ (1)][.zip]`; zip lub katalog; UTF-8, TAB, nagłówek, trim wartości; duplikat → najpóźniejsza „Data wytworzenia danych” z `metadane.txt`, remis → bez sufiksu `(1)`; katalog i zip tego samego nadleśnictwa = ten sam kandydat (preferuj zip przy remisie).
- Złączenie: `G_SUBAREA.a_i_num = arodes_int_num`; `id` = `adr_for` bez białych znaków.
- Partnerzy: piętra `DRZEW`, `IP`, `IIP`; gatunek panujący = `sp_rank_order_act = 1` w pierwszym piętrze (`DRZEW` lub `IP`); kody gatunków normalizowane `normalize_species_code`.
- `SHARE_WEIGHT`: `PJD` 0.2, `MJS` 0.3, `1` 0.5, `2` 0.7, `3` 0.7, `4`–`10` 0.9; nieznany/pusty 0.3. Ocena partnera = max(panujący-partner: `1.0 × age_factor(wiek panującego)`; domieszka-partner: `SHARE_WEIGHT × age_factor(wiek domieszki)`, brak wieku → `AGE_UNKNOWN_FACTOR`). `habitat_score` = ocena partnera × `habitat_factor` (bez osobnego mnożenia przez wiek panującego).
- Odpowiedniki kodów: `LMWYZSW≙LMWYZ`, `LWYZSW≙LWYZS`, `BMWYZSW≙BMWYZ`, `BMWYZW≙BMW`, `LMGW≙LMW`, `BMGW≙BMW`, `BWG≙BW`, `BMGB≙BMB`, `BGB≙BB`, `LMG≙LMGSW`, `LWYZ≙LWYZS`, `LG≙LGSW`; bez odpowiednika: `LL`, `LLWYZ`, `LLG`, `OL`, `OLJ`, `OLJWYZ`, `OLJG`, `OLG`, `LMB` (każdy kod z nazwą w `content/gatunki.yaml`).
- Obszar = suma obrysów wszystkich nadleśnictw (paczki: `G_INSPECTORATE.shp`; API: kolekcja `nadlesnictwa`), uproszczona do 100 m w EPSG:2180.
- Wieluń `06-20` z OGC API (`api_districts` w `bdl_fields.yaml`), bez domieszek.
- Centroidy: `centroidy/index.json` = `{tile: 0.5, species: [...], tiles: [...]}`; `centroidy/<lat0>_<lon0>.json` = `{rows: [...]}`; `lat0 = floor(lat/0.5)*0.5` sformatowane `"%.1f"`.
- Bucket: `v/<build>/…` (`Cache-Control: public, max-age=31536000, immutable`), `manifest.json` i `live/pogoda.json` (`Cache-Control: no-cache`); `<build>` = `YYYYMMDD-HHMM` UTC + `-` + 7 znaków hash git; manifest wysyłany ostatni; `--keep N` (domyślnie 3); CORS: GET, HEAD; nagłówki `Range`, `If-Match`, `If-None-Match`; expose `ETag`, `Content-Range`, `Content-Length`.
- Env S3: `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_REGION` (domyślnie `auto`); env publiczny: `DATA_BASE_URL` (z końcowym `/`; brak → `data/`).
- Manifest: `{ "build", "base": "v/<build>/", "generated_at", "files": { "lasy": "lasy.pmtiles", "centroidy": "centroidy/index.json", "grid": "grid.json", "nazwy": "nazwy.json", "gatunki": "gatunki.json" } }`.
- Forecast healthcheck: znacznik udanego wysłania młodszy niż 36 h.
- Z gita usunięte: `web/data/lasy.pmtiles`, `centroidy.json`, `grid.json`, `nazwy.json`, `gatunki.json`; `.gitignore`: `Nadlesnictwa/`, `pipeline/data/*.duckdb`, `pipeline/data/*.parquet`, `pipeline/data/out/`.
- Nigdy nie commitować `Nadlesnictwa/`, `.superpowers`, danych dostępowych. Testy: `.venv/bin/pytest -q`, `node --test web/tests/*.test.js`.

## Review Focus

- Paczka z brakującym plikiem lub uszkodzony zip → ingest pomija nadleśnictwo z ostrzeżeniem i kończy z kodem ≠ 0 tylko gdy nie wczytał nic → test w Task 1.
- Wydzielenie bez wierszy w `f_storey_species` (D-STAN, ale brak składu) → używany `species_cd`/`spec_age` z `G_SUBAREA` → test w Task 1.
- Manifest wskazuje wersję, której pliki nie zostały w pełni wysłane (przerwany publish) → manifest wysyłany ostatni; przerwanie = stara wersja nadal działa → test w Task 5.
- Strona bez `DATA_BASE_URL` (dev) → czyta `data/` → test w Task 7.
- Promień rankingu na granicy kafelka 0,5° / obszaru bez kafelków → poprawny wynik / pusty ranking bez błędu → test w Task 7.

### Task 1: Ingest paczek do DuckDB + GeoParquet

**Files:** Create `pipeline/ingest.py`, `tests/test_ingest.py`, `tests/fixtures/bdl_pkg/` (mini paczka: 3–4 wydzielenia, wszystkie potrzebne pliki tekstowe + mały `G_SUBAREA` i `G_INSPECTORATE` zapisane z geopandas w teście lub fixture'ach); Modify `pipeline/requirements.txt` i `requirements-dev.txt` (`duckdb`, `pyarrow`), `.gitignore`.

**Interfaces — Produces:**
- `find_packages(root: Path) -> dict[str, Path]` (prefix `RR-NN` → wybrana paczka)
- `read_table(pkg: Path, name: str) -> pandas.DataFrame` (zip/katalog, TAB, trim, wszystkie kolumny jako str)

- `load_stands(db_path, parquet_path) -> GeoDataFrame` z kolumnami `id, sp_main, sp_admix (tuple, dla zgodności: kody domieszek), partners (tuple[(species, share, age|None)]), age, hab, fun, prefix, geometry`
- CLI `python -m pipeline.ingest [--packages Nadlesnictwa] [--db pipeline/data/bdl.duckdb]`
